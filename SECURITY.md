# Security policy

Personal Vault is under active development and has not undergone an independent security audit. Supported releases are published from `main`; active work continues through `development` and feature branches.

## Reporting a vulnerability

Do not publish vulnerabilities, exploit details, credentials, private media, or personal data in normal GitHub issues or discussions.

GitHub Private Vulnerability Reporting will be enabled as part of the public
release. Until then, do not share vulnerability details through public issues,
discussions, or an invented email address.

Include the affected component/commit, reproduction steps, impact, and any proposed mitigation. Please allow time for acknowledgement and remediation before public disclosure.
